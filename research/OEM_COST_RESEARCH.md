# サプリOEM製造コスト相場調査

> 実施: market-researcher / 調査日: 2026-08-04
> 目的: 「KAMIの酵母」製品原価見込み500円/30粒の妥当性検証とOEM見積依頼(RFQ)準備
> 注記: OEM各社の料金ページ直接アクセスが403でブロックされたため、数値は検索エンジン要約経由。信頼度は1段階保守的に付与。見積依頼前に各URLの直接確認を推奨。

## サマリー(30粒あたり製造原価のレンジ、ロット別)

| ロット(30粒入り個数) | 1個あたり製造原価の目安 | 根拠・信頼度 |
|---|---|---|
| 100〜500個(極小) | 約1,000〜2,000円 | 500個で総額50万〜100万円(シンギー)。信頼度: 中 |
| 1,000個 | 約700〜1,000円 | 1,000個で総額約100万円(複数出典)。信頼度: 中 |
| 3,000個 | 約400〜700円(推測) | ロット別公開単価表なし。内挿。信頼度: 低 |
| 1万個(30万粒) | 約250〜450円(推測) | 経済ロット10万粒〜(三生医薬)、加工費約6円/粒アンカーから積算。信頼度: 低 |
| 3万個以上 | 約200〜350円(推測) | 公開データなし。一般則との整合からの推測。信頼度: 低 |

要点:
- ロット別価格表を公開する国内OEMは事実上なし。公開は「総額の目安」のみ。**相見積(最低3社)必須**
- 業界一般則: 製造原価は販売価格の30〜40%。自社(500円/4,980円=原価率10%)は大幅に良好

## 「原価500円/30粒」の妥当性評価

**結論: 3,000個以上(約10万粒〜)なら射程内、1万個以上なら余裕。1,000個以下では実現困難の公算。**

1. 公開相場アンカー「1,000個=総額約100万円」=約1,000円/個。500円はその半分で、1,000個ロットでは通常届かない
2. 経済ロット10万粒=30粒入り約3,300個からスケールメリット。加工費アンカー(約5万粒で30万円前後≒6円/粒)なら30粒の充填加工費は約180円。原料費(単一原料・約9g/袋)+包材+検査按分を載せても3,000〜1万個帯で400〜700円に収まる計算(推測)
3. 有利な条件: 単一原料100%で処方設計・混合工程が最小/袋(パウチ)なら包材が安い/無味無臭で矯味不要
4. 不利な条件・最大変数: **白神こだま酵母原末の原料単価が未確認**。独占素材ゆえ供給元が限定され交渉余地が小さい可能性。髙橋先生ルート/製造元への直接確認が原価確定の最優先事項
5. 実務上の位置づけ: **初回ロットは単価より在庫リスク最小化を優先。単価500円は「3,000個以上の継続発注時の目標値」**。初回が700〜1,000円でも原価率14〜20%で事業は成立する

## ロット・MOQの相場観

- 小ロット特化型: 300〜1,000個から(50個〜の例も)
- 経済ロット: 10万粒(30粒入り約3,300個)以上
- 大手(三生医薬等)はロット大きめ

## 国内OEMメーカー候補(小ロット・GMP優先)

| メーカー | 特徴 |
|---|---|
| AFC-HDアムスライフサイエンス(静岡) | 東証上場、健康食品GMP認証工場4拠点、最小300個実績、ハードカプセル対応 |
| シンギー | 500個〜、自社GMP認証工場、多剤形 |
| 中日本カプセル(岐阜) | カプセル専業、ハードカプセル最小500個〜目安 |
| 日本インペックス | 50個〜の極小ロット標榜、GMP認証工場 |
| 三生医薬(静岡・富士) | 大手受託、カプセル技術に強み、経済ロット10万粒目安 |
| SUNAO製薬 | 小ロットOEM・販売支援が充実 |
| ニホンバイオフーヅ製造 | ハードカプセル・粉末の受託専業 |

選定観点: HACCPは2021年以降実質標準要件のため、差別化は**健康食品GMP認証(日健栄協/JIHFS)の有無**で見る。M&A DDで評価される製造記録・検査成績書を全ロット分残せる先を優先。

## 初期費用(別途費用)の目安

- 処方設計費: ゼロから10万〜50万円/単一原料なら原則不要のはず(請求時は理由確認)
- 試作費: 1万〜5万円/回(成約時無料の例あり)
- 栄養成分分析・規格試験: 数万円
- 微生物・重金属等の安全性検査(ロット毎か初回のみか要確認)
- 保存試験(賞味期限設定)費用と期間
- パッケージデザイン費(数万〜数十万円)・版代(1万〜5万円)
- シンプル設計なら初期費用合計10万〜30万円程度が目安

## OEM見積依頼チェックリスト

**A. 自社から提示する条件**
- [ ] 剤形: ハードカプセル(HPMC/ゼラチン指定。「酵母100%」訴求とカプセル基材表示の整合を確認)
- [ ] 1粒充填量(mg)、30粒/個、袋・ボトル両仕様
- [ ] 原料: 白神こだま酵母原末100%(自社支給か先方調達か、支給時の受入検査条件)
- [ ] 賦形剤・滑沢剤の要否(必要と言われたら「100%」表示が崩れるため代替案を要求)
- [ ] ロット: **1,000個/3,000個/1万個の3段階で同一仕様の単価テーブル**
- [ ] 希望納期

**B. 単価に含まれる範囲**
- [ ] 原料費・カプセル代・充填加工費・包装・出荷梱包の内訳
- [ ] 歩留まり・端数の扱い(納品保証数)

**C. 別途費用**
- [ ] 上記「初期費用の目安」の各項目の有無と金額
- [ ] MOQと価格改定条件(原料高騰時の転嫁ルール)

**D. 品質・体制(DD観点でも重要)**
- [ ] 健康食品GMP認証の有無・認証番号
- [ ] ロット毎の製造記録・検査成績書の発行可否と保管期間
- [ ] 異物混入・回収時の対応フローとPL保険
- [ ] 原料トレーサビリティ(産地証明・受入記録)
- [ ] 支払条件・リードタイム・在庫保管サービスの有無

## 調査の限界

1. 一次ページ直接閲覧不可(403)。数値は検索要約経由で転記誤差の可能性
2. ロット別公式単価表は非公開。3,000個以上の単価は内挿・推測(信頼度: 低)
3. 単一原料と混合処方の価格差の定量データなし
4. **白神こだま酵母原末の原料単価は未確認**(原価試算の最大の不確実要因)
5. 出典の多くがOEMメーカー自身の販促記事でバイアスの可能性
6. 記事発行日は概ね2023〜2025年推定。原材料高騰局面では上振れ可能性
